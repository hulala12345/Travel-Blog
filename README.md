# Travel Blog

This project provides a simple travel blog website built with HTML, CSS and JavaScript. It demonstrates how to list travel stories, place map markers, showcase food experiences and browse photos in a gallery.

## Features

- Display travel stories with titles, summaries and cover images.
- Show map markers for each travel location using Leaflet.
- Filter stories by location tag.
- Display food experiences in a separate list.
- Photo gallery with image preview.
- Timeline navigation sorted by date.

## Running the site

Open `public/index.html` in your browser. The page loads sample data from the `data` folder and requires internet access to load Leaflet and placeholder images from their CDNs.

You can replace the contents of `data/posts.json` and `data/food.json` with your own travel journal and food review data.
